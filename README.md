# Admin Dashboard - Healthy Food Delivery

لوحة تحكم إدارية احترافية مبنية بـ Next.js 14 و TypeScript لإدارة منصة توصيل الطعام الصحي.

## ✅ الميزات المكتملة

### 🏠 لوحة التحكم الرئيسية
- **KPIs شاملة**: عرض إحصائيات المطاعم، الطلبات، الإيرادات، والعملاء
- **الطلبات الحديثة**: جدول تفاعلي بأحدث الطلبات مع التفاصيل
- **تحديث تلقائي**: البيانات تتحدث كل 30 ثانية

### 🏪 إدارة المطاعم
- **CRUD كامل**: إضافة، تعديل، حذف المطاعم
- **تبديل الحالة**: تفعيل/إلغاء تفعيل المطاعم بنقرة واحدة
- **تصنيف المطابخ**: تمييز بين المطابخ السحابية والمطاعم الشريكة
- **إحصائيات مفصلة**: عدد المطاعم النشطة والمطابخ السحابية

### 📋 إدارة عناصر القائمة
- **واجهة بطاقية**: عرض جذاب للوجبات مع الصور
- **تصفية متقدمة**: حسب المطعم والفئة
- **شارات صحية**: تمييز الوجبات الصحية
- **إدارة شاملة**: إضافة، تعديل، حذف العناصر مع تفاصيل كاملة

### 📦 إدارة الطلبات
- **جدول تفاعلي**: عرض جميع الطلبات مع التفاصيل
- **تصفية بالحالة**: علامات تبويب لكل حالة طلب
- **تعيين المناديب**: واجهة سهلة لتعيين المناديب للطلبات
- **تحديث الحالة**: تغيير حالة الطلب مباشرة من الجدول
- **إحصائيات حية**: عدد الطلبات لكل حالة

### 🎫 إدارة الكوبونات
- **إنشاء متقدم**: كوبونات مخصصة أو عشوائية
- **تتبع الاستخدام**: شريط تقدم لاستخدام الكوبونات
- **إدارة التواريخ**: تحديد فترة صلاحية الكوبونات
- **حدود يومية**: تحكم في عدد الاستخدامات اليومية

### 👥 إدارة المستخدمين
- **عرض شامل**: جميع المستخدمين مع أدوارهم
- **بحث وتصفية**: بالاسم، الهاتف، أو الدور
- **إحصائيات المستخدمين**: تحليل التسجيلات والنشاط

### 🚚 إدارة المناديب
- **إدارة الحالات**: متاح، مشغول، غير متصل
- **إضافة مناديب**: واجهة سهلة لإضافة مناديب جدد
- **تتبع الأداء**: نسب المناديب حسب الحالة

## 🛠️ التقنيات المستخدمة

- **Next.js 14** - App Router
- **TypeScript** - Type Safety
- **TailwindCSS** - Styling
- **React Query** - Data Fetching
- **React Hook Form** - Form Management
- **React Hot Toast** - Notifications
- **Lucide React** - Icons
- **Date-fns** - Date Formatting
- **Supabase** - Backend & Database

## 🚀 كيفية التشغيل

### 1. تثبيت Dependencies

```bash
npm install
```

### 2. إعداد متغيرات البيئة

انسخ ملف `env.example` إلى `.env.local` وأضف معلومات Supabase:

```bash
cp env.example .env.local
```

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. تشغيل الخادم

```bash
npm run dev
```

سيعمل التطبيق على `http://localhost:3000`

## 📊 قاعدة البيانات

يتطلب التطبيق الجداول التالية في Supabase:
- `users` - المستخدمين
- `restaurants` - المطاعم  
- `menu_items` - عناصر القائمة
- `orders` - الطلبات
- `couriers` - المناديب
- `coupons` - الكوبونات
